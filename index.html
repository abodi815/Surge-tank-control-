Mathematical model and interpretation

Each calculated quantity comes from the equations below.

1 · Nonlinear dynamic mass balance
A·dh/dt = Fᵢₙ(t) − Cᵥ√h
The exact nonlinear model used for the simulated tank level.
2 · Steady-state level
h* = (Fᵢₙ/Cᵥ)²
At equilibrium, inlet flow equals gravity outlet flow.
3 · Local first-order model
ΔH(s)/ΔFᵢₙ(s) = Kₚ/(τs + 1)
A small-signal approximation around one positive steady operating point.
4 · Process gain and time constant
Kₚ = 2√h*/Cᵥ
τ = 2A√h*/Cᵥ
Kₚ is level sensitivity; τ describes local response speed.
5 · Local stability
λ = −Cᵥ/(2A√h*) = −1/τ
For A > 0, Cᵥ > 0 and h* > 0, λ is negative and the equilibrium is locally asymptotically stable.
6 · Hydrostatic gauge pressure
Pbottom − Ptop = ρgh
Density affects pressure; it does not enter this volumetric-flow level balance.

How to read the results

Short explanations of the main process-dynamics concepts.

Stability is not the same as speed

For a positive fixed inlet flow, the tank has a positive stable equilibrium. Below equilibrium, inlet flow exceeds outlet flow and the level rises. Above equilibrium, outlet flow exceeds inlet flow and the level falls.

A stable system can respond slowly or quickly. The time constant describes local response speed; the sign of the pole determines local stability.

Why gain and time constant change differently

Tank area changes τ but does not change the equilibrium height or the static process gain for a fixed inlet flow and outlet coefficient. Changing Cᵥ or the operating level changes both gain and time constant.

The linearized curve is a local approximation. Large disturbances move the system far from its original operating point, so the nonlinear and linear curves may differ.

Equilibrium versus tank capacity

A mathematically stable equilibrium can lie above the physical tank height. In that case, the ideal model predicts a stable level, but a real tank would overflow first. Stability does not mean that the operating condition is safe.

What density changes in this model

With volumetric inlet and outlet flows and a fixed outlet coefficient, changing density changes the hydrostatic pressure at a given height. It does not change the predicted level trajectory. A model including viscosity or density-dependent discharge behavior would require additional hydraulic relationships.
